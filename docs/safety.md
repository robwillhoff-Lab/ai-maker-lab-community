# Parent administration and safety boundaries

Use separate ordinary learner accounts and separate workspaces. Parents manage
software installation, account access, backups, and service choices. The alpha
installer scopes its files to the current account; it does not create learner
accounts or enforce child isolation. Validate separate account permissions
without granting administrator access to learners.

A launcher is not a security boundary. Neither a ChatGPT URL allowlist nor a
“Parent” settings label provides authentication or general web filtering. Linux
file permissions, reviewed Codex sandbox/approval settings, service controls,
and active adult supervision need separate validation.

Codex approvals and its filesystem/network sandbox are distinct controls, as
explained by [official OpenAI documentation](https://learn.chatgpt.com/docs/sandboxing).
Parents must explicitly review both in each learner session;
this repository does not install a Codex policy or claim a safe default.

Before enabling services, parents must verify current age eligibility, account
terms, privacy choices, and access arrangements with each provider. Eligibility
for child use has not been established by this technical preparation. Avoid
sharing personal details, credentials, or private projects with AI services.
Keep account credentials outside code and examples. Review generated commands
and downloaded dependencies before execution. Adults approve printer operation,
materials, and physical safety. Review game content and online/multiplayer access.
