# Teaching workflow

1. Imagine: describe one idea to Maker Coach without personal information.
2. Predict: choose one small goal and say what you expect to happen.
3. Build: copy a minimal task into Codex in your own Code workspace.
4. Test: run it, observe the result, and compare with your prediction.
5. Explain: report what changed, what worked, and what you learned to Coach.

Example handoff: “Help me build a number guessing game. Teach one concept at a
time. Ask me to predict, edit, test, and explain. Ask an adult before changing
software or settings outside my project.”

Report back: goal; prediction; changes; tests and observations; lesson learned;
next question. Keep project notes and journal entries private. Copying between
Coach and Codex is manual; review copied text for personal information first.
Teaching instructions guide behavior but do not enforce operating-system access.
